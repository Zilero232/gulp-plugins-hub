gulp-plugins-hubTyped plugins for gulp 5

Pug, Sass, Lightning CSS, terser, sharp, fonts, archives and cache-busting — one consistent API, validated options, real errors.

All plugins
GitHub

Built for gulp 5

ESM packages for Node.js 22.13+, binary files guarded against gulp 5's UTF-8 default, source maps that work with src and dest's own sourcemaps option.

Options checked up front

Every option is validated when the plugin is created. A typo or a wrong type fails with a list of what is wrong, instead of a build that silently does nothing.

Modern engines

Lightning CSS instead of clean-css and autoprefixer, html-minifier-next, sass-embedded with one compiler per build, sharp for WebP and AVIF, WebAssembly fonts.

Follows the gulp guidelines

Files without contents pass through, errors are PluginErrors prefixed with the plugin name and emitted, never thrown, and gulp is never a dependency.

Fully typed

Written in TypeScript with declarations for every option and hook. Hooks get the Vinyl file, so they can decide per file.

Make your own

The plugin factory the hub is built with turns a transform function into a well-behaved plugin, with testing helpers for Vitest or node:test.
